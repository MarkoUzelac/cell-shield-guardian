# Cell Shield Guardian

Cell Shield Guardian is a privacy-focused web application for defensive privacy awareness, browser diagnostics, connection checks, and research-oriented analysis.

## Core goals

- Help users understand what their browser and connection reveal about privacy and security.
- Support defensive mobile-network and privacy research using lawful, passive, or self-captured data.
- Provide clear explanations and real measurements instead of fabricated security results.
- Keep sensitive analysis local where technically possible.

The production site uses `https://cellguardian.online/` as its canonical URL and Open Graph URL. Structured data identifies the project as the free **Cell Shield Guardian** web application.

## Security and ethics

This project is intended for educational, research, and defensive privacy protection purposes only. Do not use it to intercept, track, or analyze communications or devices that you do not own or are not explicitly authorized to test. Active radio interception and related activities may be regulated by local law.

## Development

Prefer working locally? You need Node.js and npm.

```sh
git clone https://github.com/MarkoUzelac/cell-shield-guardian.git
cd cell-shield-guardian
git checkout cellguardian
npm install
npm run dev
```

The current application source is maintained on the `cellguardian` branch.

This project is built with Lovable. Changes made through Lovable are synchronized to this repository.
